# EIMS-NF-006: Responsive Desktop and Tablet UI Test Report

## 1. Requirement Details

* **Requirement ID:** EIMS-NF-006
* **Requirement Name:** Verify Responsive Desktop and Tablet UI
* **Test Case ID:** TC-UX-02
* **Test Type:** Manual UI Testing

## 2. Objective

Verify that the Electronics Store Inventory Management System remains usable on desktop and tablet screen sizes.

## 3. Test Environment

* **Browser:** Google Chrome
* **Testing Tool:** Chrome Developer Tools Device Toolbar
* **Application:** Electronics Store Inventory Management System

## 4. Test Cases

| Test Case  | Viewport   | Expected Result                                                   | Actual Result                    | Status |
| ---------- | ---------- | ----------------------------------------------------------------- | -------------------------------- | ------ |
| Desktop UI | 1280 × 800 | Dashboard, navigation, tables, forms, and controls remain usable. | Application behaved as expected. | PASS   |
| Tablet UI  | 768 × 1024 | Layout remains usable without unexpected overlapping or clipping. | Application behaved as expected. | PASS   |

## 5. Features Verified

* Dashboard widgets and inventory charts
* Components inventory table
* Delete buttons and interactive controls
* Page layout and scrolling
* General UI usability at both viewport sizes

## 6. Conclusion

The application was manually tested at desktop and tablet viewport sizes. All checked features behaved as expected, and no unexpected layout issues were observed.

**Overall Result: PASS**
